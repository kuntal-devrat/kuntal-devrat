### ⚡ Focus & Architecture

I engineer **hardware-accelerated systems**, **GPU compute pipelines**, and **autonomous agent runtimes**. My work bridges low-level zero-cost abstractions with modern machine learning infrastructure.

- **GPU & Accelerated Computing:** Architecting WebGPU (WGSL) compute kernels, hardware-agnostic execution engines, and vectorized SIMD intrinsics (`AVX-512` / `AVX2` / `NEON`).
- **Autonomous Agent Runtimes:** Building deterministic execution layers, sensory feedback loops, and zero-latency tool-dispatch runtimes for local and in-browser agents.
- **Compilers & Systems:** Authoring declarative query compilers, polyglot runtimes with sub-millisecond cold starts, and IEEE 754 interval arithmetic libraries.
