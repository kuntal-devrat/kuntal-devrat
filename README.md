## ⚡ About Me

- 🎓 **Specialization**: Computer Science & Engineering in **Artificial Intelligence & Machine Learning**.
- 🚀 **Systems & Accelerated Computing**: Architecting GPU-accelerated compute pipelines using **WebGPU (WGSL)**, zero-cost abstractions in **Rust**, and vectorized SIMD kernels (**AVX-512 / AVX2 / NEON**).
- 🧠 **AI & Automation Runtimes**: Building deterministic execution frameworks and autonomous agent runtimes for local and cloud environments.
- 🔬 **Polyglot & Compilers**: Author of **PipeQL** (declarative query compiler) and numerical precision libraries with hardware-directed rounding.
